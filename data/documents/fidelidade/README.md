# Documentos de fidelidade da Company

Esta pasta contém os documentos usados como fonte de conhecimento pelo RAG do Company Smart Loyalty.

## Documentos iniciais

- `company_fidelidade.md`: síntese estruturada do texto fornecido de uma página pública de programa de fidelidade.

## Como adicionar novas fontes

1. Adicione o documento nesta pasta ou em uma subpasta apropriada.
2. Registre a URL de origem, a data de captura e o método de obtenção.
3. Verifique se o conteúdo foi obtido de forma autorizada.
4. Confira se o texto está completo e legível.
5. Execute as validações documentais antes da indexação.
6. Atualize o índice e registre o resultado da operação.

## Formatos previstos

- Markdown (`.md`)
- Texto simples (`.txt`)
- PDF (`.pdf`), quando a extração de texto for confiável.

## Regras de qualidade

- Não indexar páginas de erro como documentação.
- Não inventar informações ausentes na fonte.
- Não substituir a última versão válida quando uma atualização falhar.
- Preservar a proveniência dos documentos.
- Separar fatos, inferências e recomendações geradas por IA.
- Rever documentos que possam ficar desatualizados.
